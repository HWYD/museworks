# 安全与隐私规则

## Electron 密钥边界

- Ark API Key 可由 Electron Main 使用 `safeStorage` 加密后持久化；其他 API Key、令牌、刷新令牌、私钥和用户凭据只能在 Electron Main 或受保护的系统存储中读取和使用。
- Electron Main 仅可通过受控内存或匿名管道把解密后的 Ark API Key 交给本地 Python 服务使用；不得写入命令行参数、环境文件、普通文件或持久化数据库。
- Python 服务不得持久化、记录或回传 Ark API Key，用毕应释放持有它的受控内存；Renderer 与 Preload 在任何时刻都不可见该密钥。
- 渲染进程不得读取环境变量、系统钥匙串或包含密钥的配置文件。
- preload API 不得返回密钥本身；只返回完成受控操作所需的结果或状态。
- IPC 请求不能接受“读取任意密钥”或“执行任意网络请求”这类泛化能力。
- Electron Main 与 Preload 不得把本机 FastAPI 转化为通用 HTTP 或 IPC 转发能力；普通业务只可由受控 Renderer 本机客户端直接请求。
- 日志、异常、遥测、崩溃报告、截图和测试快照均不得包含密钥或完整授权头。

## 输入与数据

- 将 IPC 参数、文件路径、外部 URL、模型输出和持久化内容都当作不可信输入。
- 对路径做规范化和允许范围检查，防止路径穿越及任意文件读写。
- Workspace `rootPath` 仅可由 Main 通过具名 IPC 返回给 Renderer，前提是该目录由用户在原生选择器中明确选择、已规范化并确认存在；Renderer 不得将该路径回传为任意文件操作参数。
- 对网络请求使用显式允许的端点、方法和超时；避免把用户输入直接拼入 URL 或命令。
- Renderer 仅未来可通过 `apps/desktop/src/renderer/lib/local-agent-client.ts` 使用原生 `fetch` 与 `EventSource` 请求 `http://127.0.0.1:8765/v1/**`；不得访问外部网络、其他 loopback 地址、ComfyUI 或网络旁路 API。
- 首个该类 API 功能前，必须为开发态 `http://127.0.0.1:5173` 与打包态 `museworks://app` 配置精确 CORS，且 CSP 只加入 `connect-src http://127.0.0.1:8765`；不得使用 CORS `*`、凭据或放宽其他 CSP、Electron 隔离设置。
- 显示错误时使用脱敏后的可操作信息，诊断上下文只保留在受控日志中。
- 不提交 `.env`、密钥文件、用户数据、生产数据库导出或未脱敏响应夹具。

## 资源与运行时

- 本地模型运行时以 RTX 3060 Ti 8GB VRAM（显存）为开发参考门禁；启动前分别探测 GPU 显存与系统内存，任一资源不足时拒绝或降级。
- 默认未来生成基线为 `batch=1`、`768x768`、`preview=none`，并采用动态显存或 CPU offload；`1024x1024` 仅可在目标 RTX 3060 Ti 8GB VRAM 实机门禁通过后启用。
- 不因重试、并发或模型预加载突破资源边界；所有队列和重试都应有上限。
- 下载模型、启用远程服务或收集遥测前，应明确告知数据流向并获取所需授权。

## 审核

- 新增跨进程能力、文件访问或联网能力时，审查最小权限、输入校验、错误脱敏和取消路径。
- 安全修复不应通过隐藏错误或放宽校验实现；应保留可验证的失败行为。
