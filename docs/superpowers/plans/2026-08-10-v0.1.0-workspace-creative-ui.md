# MuseWorks v0.1.0 工作区与创作界面

## 目标

交付第一版本地工作区产品外壳：用户选择目录、类型化原生 IPC、最近工作区持久化，以及仅由 Mock 创作数据驱动并与 Pencil 设计稿对齐的工作台界面。

## 接口变化

- 新增 Workspace、CreativeTask、CreativeRun、RunStep、Artifact 与 GenerationOptions 的 Zod 领域契约。
- 新增具名且经过校验的 `workspace.load`、`workspace.pick` 与 `workspace.activate` Preload API。
- 仅在 Electron `userData` 中持久化经过校验、由用户明确选择的工作区元数据。
- Composer 使用本地 TipTap 纯文本编辑器；不新增 Renderer 特权、网络调用或领域契约。

## 实现分组

1. 收紧工作区路径 IPC 规则，并为 Renderer 初始化 Tailwind 与 Shadcn。
2. 新增契约与契约测试，再实现 Main 持久化/目录选择处理和 Preload 校验及调用方、处理方测试。
3. 依据 Pencil 屏幕构建 Workspace Picker 和三栏创作工作台；Mock fixture 必须独立于 UI 组件，并以 TipTap 实现紧凑的纯文本 Composer。

## 测试

- 校验全部新增 Zod 契约和工作区 IPC 成功、取消、错误结果。
- 覆盖目录取消、无效目录、最近记录持久化和最近工作区选择。
- 覆盖 Picker、工作区切换、Empty/Generating/Complete/Error、TipTap 的可访问输入与 Ctrl/Cmd+Enter 提交，以及 Renderer 权限边界。

## 假设

- 用户只选择已有目录；v0.1.0 永不创建工作区目录。
- Main 仅可通过具名 Workspace 契约向 Renderer 透露已验证且由用户明确选择的工作区根目录；这不授予 Renderer 文件系统权限。
- 不引入 FastAPI、SSE、Agent Runtime、真实图片生成或 Artifact 持久化。
- TipTap 仅保留普通文本编辑与换行；不实现 `/` 命令、`@` 提及、Suggestion 菜单或任何 AI 连接。
