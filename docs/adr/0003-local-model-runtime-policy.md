# ADR-0003：本地模型运行时策略

## 状态

已接受。

## 背景

开发参考硬件为 RTX 3060 Ti 8GB VRAM（显存）。这是 GPU 显存约束；系统内存需要独立探测和记录。模型推理和图像生成可能同时占用 GPU 显存与系统内存，且 Ark 与 ComfyUI 的实际能力和部署条件不同。

## 决策

- 以 Ark 承担远端模型与推理接入；Ark 是 Agent Runtime 调用的模型 Provider Adapter。
- ComfyUI 作为独立图像工作流能力，经 Tool 与 ComfyUI Adapter 调用，不由 Renderer 直接控制。
- 默认未来生成基线为 `batch=1`、`768x768`、`preview=none`，并采用动态显存或 CPU offload。
- `1024x1024` 仅可在目标 RTX 3060 Ti 8GB VRAM 实机门禁通过后启用；未经实测不得宣称稳定支持固定并发或常驻高资源模型。
- 系统内存与 GPU 显存分别探测、记录和验收，不能用其中一个代替另一个。

## 后果

- 对低资源设备更保守，产品文案与验收必须以实测数据为依据。
- 调用方需要能够呈现资源不足、服务不可用和任务失败等可恢复状态。
- 后续若引入本地模型运行时，必须新增 ADR 评估 GPU 显存、系统内存、下载、隔离和降级策略。
