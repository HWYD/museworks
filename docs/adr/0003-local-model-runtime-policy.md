# ADR-0003：本地模型运行时策略

## 状态

已接受。

## 背景

目标设备的内存基线为 8GB。模型推理和图像生成可能占用大量内存，且 Ark 与 ComfyUI 的实际能力和部署条件不同。

## 决策

- 以 Ark 承担远端模型与推理接入，通过 Adapter 隔离其 API 细节。
- ComfyUI 作为独立图像工作流能力，经 Tool 与 Adapter 调用，不由 Renderer 直接控制。
- 8GB 内存仅定义兼容性约束；默认采用按需使用和可恢复的调用方式。
- 未经目标环境实测，不得宣称稳定支持 1024 级图像生成、固定并发或常驻高资源模型。

## 后果

- 对低资源设备更保守，产品文案与验收必须以实测数据为依据。
- 调用方需要能够呈现资源不足、服务不可用和任务失败等可恢复状态。
- 后续若引入本地模型运行时，必须新增 ADR 评估内存、下载、隔离和降级策略。
