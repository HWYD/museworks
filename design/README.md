# Museworks 设计资产

本目录存放 Museworks 的可编辑设计源文件和长期保留的视觉参考，不属于应用运行时资源。

## AI 生图工作台

- 源文件：`museworks-image-workbench.pen`
- 参考图：`references/ai-image-workbench-reference.png`
- 临时预览：`exports/`（已忽略，不提交）

该设计稿以 1440 × 1024 的桌面内容区为基准，采用浅色 Shadcn 风格与靛紫主色。画布包含空白、生成中、完成、失败/重试四个状态页；生成结果只使用占位卡，不含生成图片素材。

### 状态语义

- 空白：引导填写提示词，结果区展示空状态。
- 生成中：以 2 × 2 加载占位卡表达候选图仍在生成，并提供取消操作。
- 完成：以带编号的中性占位卡表达四个候选结果，并提供生成变体操作。
- 失败/重试：保留 2 × 2 网格，以错误占位卡、错误提示和重新生成操作表达可恢复失败。

参考图只用于还原结果区的网格比例、间距、圆角和信息层级；不复制、嵌入或生成其中的咖啡图片。

## 编辑约定

`.pen` 是 Pencil 的加密二进制设计源文件，只能在 Pencil 中或通过 Pencil MCP 编辑，不能直接用文本工具读取或修改。请在 Pencil 中打开项目内的源文件后再开始编辑；同一时段避免多人同时修改该文件，以免产生二进制合并冲突。

导出的 PNG、PDF 或 HTML 仅用于临时评审，放在 `exports/`。需要长期保留的参考素材放在 `references/` 并随设计源文件提交。
